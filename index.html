Depict AI Documentation¶

Welcome to the comprehensive documentation for Depict AI - an image data tool for computer vision, covering everything from raw images to model training and fine-tuning.

🚀 What is Depict AI?¶

Depict AI is a full-stack application designed for:

  • Data Visualization - View and explore image datasets
  • Annotation - Manual and AI-assisted image annotation
  • Dataset Management - Organize and manage computer vision datasets
  • Data Cleaning - Quality control and dataset curation
  • CV Tasks - Classification, object detection, and segmentation
  • Media Support - Images and videos

🔧 Tech Stack¶

Backend: - FastAPI (Python 3.12+) - SQLModel (SQLite/PostgreSQL) - OAuth2 + JWT authentication - Sentry monitoring

Frontend: - Vue.js 3 (Composition API) - Vite build system - Lucide Vue icons - Modern CSS with variables

Infrastructure: - Poetry for Python dependency management - Docker for containerization - MkDocs for documentation
